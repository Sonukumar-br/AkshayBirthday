# Audio File Instructions

If you wish to add background music to the website:

1. Add your MP3 music file to this directory (`public/audio/`).
2. Rename it to: `birthday.mp3`

The audio button on the top navigation bar (`🔊 Audio`) will play/pause `public/audio/birthday.mp3`.
If no audio file is provided, all synthesize keystrokes, candle blow sound effects, and confetti chimes will still work automatically using Web Audio API!
